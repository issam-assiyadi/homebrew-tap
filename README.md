# Issam-assiyadi Tap

## How do I install these formulae?

`brew install issam-assiyadi/tap/<formula>`

Or `brew tap issam-assiyadi/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "issam-assiyadi/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
